# DOC-REGISTRY

The doc freshness tracker: one row per maintained doc, its **update trigger**, and
its **last-verified** date. If a change fires a trigger, update the doc *and* bump
its row here in the same change. A new maintained doc gets a new row, same change.

This is the mechanism behind the docs-in-sync law: a doc with a stale
last-verified date against a trigger that has since fired is a bug, same as a
missing changelog entry.

Entry-point tracker: ALL-CAPS, no frontmatter.
