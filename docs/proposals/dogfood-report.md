# Proposal — a "Measured on itself" README section

**The README's demo is seeded; cage's own development ledger is real.** Weeks of heavy
agent use built cage — that ledger is the one artifact no reader can argue with, and it
is currently invisible.

## What it is

A short README section with real numbers from cage's own `~/.cage` + project ledger:
total spend by agent · graphify receipts (gross-labelled) · the adoption asymmetry ·
UNPRICED honestly counted. Generated by a command a reader can run on their own ledger
the same day they install.

## Rules (all standing law, restated because marketing is where they die)

- **ZERO dummy data** — run on the real ledger (dev machine; the Cowork sandbox cannot).
- Numbers keep their method tags **in the README** — a `modeled` stays labelled.
- Gross keeps the gross note; UNPRICED is shown, not trimmed.
- Dated + versioned ("as of v0.37.1, 2026-08"), refreshed at each release via a
  release-checklist line — a stale dogfood number is the `cage_version` drift again.
- PII: the ledger is counts-only by construction; still review before pasting.

`cage report` + `insights attrib` + `insights adoption` (once ADOPT ships — or without
it, v1 now) on the dev machine → paste, label, link. An hour. Replaces the
