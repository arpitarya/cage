# GF-LAUNCHER — the interceptor cannot reach cage under --python-launcher

Under `--python-launcher` there is no `cage` on PATH, so **neither graphify twin meters**
(shim contract B5). A stated gap, named in `cage doctor`'s `launcher-gap` check, not a
half-fix.

**This is a decision, not a build.** Three options (setup-time twin variants · a runtime
interpreter arm · accept the gap) are argued in
[compare/gf-launcher-metering.compare.md](../compare/gf-launcher-metering.compare.md);
**proposed verdict B**, awaiting your accept or override.

## The constraint any fix inherits

**A fix must move both twins together.** The POSIX `graphify` and Windows `graphify.cmd`
are a hand-paired twin pair against one written contract
([shim-contract.md](../shim-contract.md)); the marker set already has three necessary
copies. Changing one twin alone silently disables liveness detection *and* re-enables the
stacked-shim recursion.
