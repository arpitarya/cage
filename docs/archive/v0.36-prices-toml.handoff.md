# Handoff: split model prices into `.cage/prices.toml`

**One-liner:** Move the model price table out of `cage.toml` into its own
`.cage/prices.toml` — vendor facts get their own file with their own lifecycle,
so `cage prices sync` becomes a file replacement instead of text surgery inside
user policy. **The money must not move by a cent.**
**Owner / executor:** Claude Code
**Model:** **Opus** — this is the money path. A dropped or mis-resolved price row
doesn't crash; it silently reprices calls to UNPRICED, or worse to a family match
that looks plausible. Diagnosing that after the fact is far harder than getting
the split right once.
**Status:** Ready to build
**Stress-tested:** Challenged: is this worth doing at all, or just tidiness? →
Worth it, and measurable: **400 of the bundled config's 568 lines are price
rows (70%)**, so `cage prices sync` currently performs text surgery inside a file
dominated by data the user never edits, and `prices sync` / `policy sync` are
told apart only by which keys they touch inside one shared `[meta]`. Challenged:
move `[alias]` too (the original draft) → **rejected by Arpit, correctly** — an
alias describes *your* environment, not a vendor rate card, and must survive a
wholesale price sync. That correction produced the governing rule: **vendor facts
move, routing decisions stay.** Riskiest assumption: that the split is
semantically inert — mitigated by making `policy.load` still return one merged
dict and by a byte-identity acceptance bar rather than a "does it parse" one.
Residual: `[meta]` splits *per key*, and a mis-split silently stops a staleness
check firing — called out explicitly below.
**Standing constraint: DO NOT COMMIT in `cage/`.**

## 2. Definition of done

**The move**

- [ ] `.cage/prices.toml` holds: every `[prices.<provider>.<model>]` table,
      `[credits]`, and **only** `prices_version` + `prices_date` from `[meta]`
- [ ] `cage.toml` keeps everything else — including **`[alias]`**,
      `[tools.<tool>] price_at`, and `cage_version` + `policy_version`
- [ ] **`[meta]` splits per key** — a mis-split silently stops a staleness check
      firing, which is a quiet failure, the worst kind cage has

**Resolution + migration (reuse the `policy.toml → cage.toml` pattern exactly)**

- [ ] **One resolution point** — `Footprint.prices`: `prices.toml` → legacy
      in-`cage.toml` tables → bundled default. No second filename literal anywhere
- [ ] Both present ⇒ `prices.toml` wins **and** a one-line warning names the
      ignored legacy block (mirror `shadowed_config`)
- [ ] `cage setup` migrates: move the §2 tables out of `cage.toml` into
      `prices.toml`, leave a pointer comment. Idempotent; non-destructive when
      both exist; fail-open
- [ ] **`policy.load` still returns ONE merged dict** — this is a *file* change,
      not an API change. Every consumer (`prices.call_usd`, `policy.price_match`,
      `convert`, `receiptprice`) reads the same shape as today
- [ ] Bundled data splits: `cage/data/cage.toml` → `+ cage/data/prices.toml`;
      `pyproject.toml` package-data updated; **zipapp resolves both** via
      `paths.bundled_data()`
- [ ] `cleanup.NEVER` protects `prices.toml` alongside `cage.toml` and the legacy
      `policy.toml`
- [ ] The **global `~/.cage`** config splits the same way
- [ ] `prices.toml` is **committed** (documented as such), like `cage.toml`

**Command surfaces**

- [ ] `cage prices set` → writes `prices.toml`
- [ ] `cage prices alias` → writes **`cage.toml`** (routing decision)
- [ ] `cage prices route-tool` → writes **`cage.toml`** (routing decision)
- [ ] `cage prices sync` → **replaces the cage-managed region of `prices.toml`**;
      rows marked `# cage:custom` still survive
- [ ] `cage policy sync` → unchanged, now unambiguously `cage.toml`-only
- [ ] `cage doctor` names the active prices file and flags a shadowed legacy block

**Acceptance — numerical, not structural**

- [ ] On a real ledger: `cage report`, `cage insights attrib`, `cage insights roi`
      **byte-identical** before vs after the split
- [ ] **UNPRICED row count unchanged by one row**
- [ ] Every `[prices.*]` table present before resolves after — **count them**,
      don't eyeball
- [ ] `policy.price_match` returns the same kind (`exact|alias|family|none`) for
      a sampled set of real model ids — a silent `exact`→`family` degradation is a
      wrong number wearing a plausible tag
- [ ] A legacy project (prices still in `cage.toml`) reads identically via the
      fallback
- [ ] `cage setup` migration run twice changes nothing
- [ ] `pytest -q` green; determinism tests unchanged in shape
- [ ] `docs/IMPLEMENTATION.md` per milestone; **cage tree uncommitted**

## 5. Non-negotiables

- **The money does not move.** Byte-identical money views is the bar.
- One resolution point; never a second filename literal.
- Never a breaking change — legacy in-`cage.toml` prices keep working via
  fallback (users on released versions have them).
- stdlib-only; fail-open write paths; `CageError` at the CLI boundary;
  determinism and the `method` law untouched.
- **DO NOT COMMIT in `cage/`.**
