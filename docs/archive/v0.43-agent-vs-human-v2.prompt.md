## Task

Four phases, strictly in order, **each shipped alone with the suite green**:

1. **P1 — capture re-wire + line-match (substrate).** `parse_edits` in
   `transcript.py`; commit-window resolution (never HEAD-at-import); transient
   line-matching; provenance rows `method="transcript"` with additive-optional
   counts (`suggested`, `kept`, `kept_modified`, `dropped`, `agent_lines`);
   `[authorship]` config table. **Phase gate:** dogfood on the cage repo itself —
   report rows written, match rate, unknown rate. If the window join misassigns,
   STOP and surface it; do not proceed to P2 on a broken join.
2. **P2 — `cage/commitjoin.py`.** Commit windows from git log; task-id join first
   (reuse `taskgroup.join_rows` — do not fork a second join); window fallback on
   `project` + ts; per-agent joinability stated (copilot-CLI and kiro excluded +
   counted); unattributed is a first-class label.
3. **P3 — views.** `cage insights commits`, `cage insights commit <sha>`,
   `cage authorship summary` — per the handoff mocks §5.4: `*`/`~`/`—` markers,
   footnotes carrying the estimator method and exclusions, Σ rows with
   counted-exclusions, `--json` envelope, CSV parity, deterministic bytes.
4. **P4 — time.** `cage task time <duration>`; wall/agent/human columns; estimator
   `max(0, wall − agent_span)` refused beyond `max_est_gap`; attested always wins.

## Constraints (hard — from handoff §6)

- stdlib only; `dependencies = []` unchanged.
- **Counts-never-content:** no line bodies, no line hashes, no commit messages, no
  author identity in any persisted row. The plant-string test must exist and pass.
- Append-only; additive-optional fields omitted at default; no new row kinds;
  `CALL_FIELDS` untouched.
- **No USD, rate, or valuation** anywhere on these surfaces.
- Refusals render (`—` + named reason); unknown never redistributed; `human`
  unmarked only via attestation; every inferred number carries `~` and its method
  in the output.
- Deterministic output; clock only in advice lines. Git: read-only shell-out, 5s
  timeout, fail-open.
- Do not touch: `verbmap` tombstones, `_is_legacy_human` guards, `test_floor.py`
  assertions, pricing/policy code.
