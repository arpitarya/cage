## Phase A — ceiling credibility (free, first)

**Question:** is `repoceiling.corpus_tokens` — which sums the **entire** graph
corpus — still defensible on a real repo, or does it become decoration?

- Run the ceiling against **cage's own** `graphify-out/` and report the figure.
- Judge it honestly: does *"an architecture question here would otherwise have read
  every file in this repo"* survive a straight face? On the 7-file golden workspace
  (≈12,761 tokens) it does. On a ~100-file repo it likely does not.
- **If it doesn't hold:** bound it — the relevant community/subgraph rather than the
  whole graph, or a cap derived from observed read counts. Keep it **deterministic**
  (same graph + files ⇒ same band) and keep it `modeled`.
- **A gates G4.** Do not surface a number more widely until you know it's credible.

**DoD:** the figure for cage's own repo, a verdict (defensible / not), and — if not
— the bounded replacement shipped with tests proving determinism.

**DoD:** a yes/no per surface tested, with the evidence, and §F's table corrected.
