# Handoff: configurable log sources (+ `surface`) and `policy.toml` → `cage.toml`

**One-liner:** Two config changes: (A) make log-source configuration complete and
**discoverable** — `[sources]` already resolves paths, but a source cannot declare
its `surface`, so a non-IDE Kiro row is mislabelled `ide`; (B) rename the config
file to `cage.toml` with a back-compat read fallback and a migration.
**Owner / executor:** Claude Code
**Model:** **Opus** — (B) touches the single resolution point every read path
depends on, and a wrong fallback silently reads the wrong config (or none) on a
real user's machine; (A) changes the substrate stamp on a row.
**Status:** Ready to build
**Stress-tested:** Challenged: does (A) fix the Kiro CLI gap? → **No, only ⅓ of
it.** `[sources]` already lets you point at a path; what's missing is the
`surface` stamp (this change) and, if the Kiro CLI store has a different shape, a
parser (**explicitly out of scope** — the format is unknown until golden-set
Phase 1 discovery; guessing it repeats the `kind:0` mistake). Challenged: hard
cutover on the rename → rejected; earlier cage versions are **on PyPI**, so real
users have `policy.toml` on disk — read-fallback + migration, never a breaking
rename. Residual: a project with *both* files; resolved by an explicit precedence
rule + a warning.

## 1. Context

- `[sources]` exists today (`paths.resolve_log_sources`, precedence **env >
  policy > built-in**; per-source `paths`/`glob`/`replace`, custom tools via
  `format = "claude|copilot|kiro"`). What it *lacks* is a `surface` key —
  `LogSource` carries `path · glob · provenance · agent · fmt` and nothing else,
  while `transcript.parse_kiro_calls` hardcodes `surface="ide"` (and the copilot
  parsers derive it from the store split).
- The config filename is **one literal in six places** (below), not the ~300
  prose mentions a naive grep suggests.

## 2. Definition of done

**A — configurable + discoverable sources**

- [ ] `[sources.<x>] surface = "cli|vscode|ide|…"` supported in **both** schema
      shapes (the `[sources.<x>]` table and the `[[sources.<x>]]`
      array-of-tables); validated against the closed set; absent ⇒ today's
      parser-derived value, byte-identical
- [ ] `LogSource` gains `surface`; `importcmd` restamps the parsed row's
      `surface` when the source declares one (same pattern as the existing
      `agent` restamp for custom tools) — **only when declared**
- [ ] A discovery surface: `cage sources list` (or `cage doctor --paths`
      extended — pick one and say why) prints every **effective** source: agent ·
      fmt · surface · path · glob · provenance (built-in/env/policy) ·
      found/missing. This is what "expose the paths" means in practice
- [ ] The scaffolded project config keeps emitting the built-in defaults as an
      **inert commented block** (verify it still does after the rename) so a user
      can uncomment and edit rather than guess
- [ ] Docs: `cage query` entry for source configuration; the config example file

**B — `policy.toml` → `cage.toml`**

- [ ] `paths.Footprint.policy` resolves **`cage.toml` first, `policy.toml` as
      fallback**; both present ⇒ `cage.toml` wins **and** a one-line warning names
      the ignored file
- [ ] Bundled data renamed `cage/data/policy.toml` → `cage/data/cage.toml`;
      `pyproject.toml` `package-data` updated (`data/cage.toml`); `MANIFEST.in`
      verified (`recursive-include cage/data *` already covers it)
- [ ] The other literals updated: `policy.py` ×2 (bundled source),
      `doctorbundle.py` (bundled-default line), `cleanup.py` `NEVER` tuple must
      protect **both** names, `explain_data.py` code_refs
- [ ] `cage setup` **migrates**: if `policy.toml` exists and `cage.toml` doesn't,
      rename it (git-friendly) and print what happened; idempotent; never
      destructive if both exist
- [ ] Write paths (`pricestoml` text surgery, `policysync`) follow the resolved
      filename — never a second hard-coded name
- [ ] `cage doctor` reports which config file is in use and flags a leftover
- [ ] Docs sweep: every `policy.toml` prose mention → `cage.toml`, with a
      one-line "previously `policy.toml`; still read as a fallback" note in
      README + `cage query`
- [ ] Goldens re-blessed **only** where the filename genuinely appears in output
- [ ] `pytest -q` green; a test proves the fallback, the precedence + warning, and
      the migration

## 3. Scope

**In:** the two changes above.
**Out (explicit):** a Kiro-CLI parser or any new source path for Kiro (format
unknown — golden-set Phase 1 discovery decides it; **do not guess**); changing
`[sources]` precedence semantics; touching the ledger schema; committing in
`cage/`; renaming anything else (`machine.json`, `study.jsonl`, … stay).

## 4. Key files

`cage/paths.py` (`LogSource`, `resolve_log_sources`, `Footprint.policy` — line
~748), `cage/policy.py` (bundled source ×2, `load`), `cage/importcmd.py` (the
restamp point), `cage/transcript.py` (parser-derived surfaces),
`cage/cleanup.py` (`NEVER`), `cage/doctorbundle.py`, `cage/doctorcmd.py`,
`cage/pricestoml.py` + `cage/policysync.py` (writers), `cage/explain_data.py`,
`cage/cli.py` (new/extended command), `pyproject.toml`, `cage/data/policy.toml`,
`docs/example/*`, tests incl. `test_sources`, `test_policysync`,
`test_pricestoml`, `test_bundled_data`, `test_zipapp`, `test_output_spec`.

## 5. Non-negotiables

- **Additive and byte-identical when unused:** no `surface` key ⇒ identical rows;
  no `cage.toml` ⇒ identical behavior reading `policy.toml`.
- **Never a breaking rename** — users on PyPI releases have `policy.toml`.
- stdlib-only; fail-open write paths; `CageError` at the CLI boundary;
  determinism unchanged; `method` untouched.
- One resolution point only — do not add a second place that knows the filename.
- **DO NOT COMMIT in `cage/`** (Arpit's standing directive).
