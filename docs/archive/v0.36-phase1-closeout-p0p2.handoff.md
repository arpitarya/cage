# Handoff: Phase 1 closeout P0–P2 (report hygiene · clear §4.5 · Kiro proxy probe)

**One-liner:** Three cheap, unpaid steps that finish everything Phase 1 can
finish without Arpit's hands: make the validation report un-misreadable, clear a
finding whose fix already shipped, and run the **last untried route to exact Kiro
token numbers**.
**Owner / executor:** Claude Code
**Model:** **Opus** — P2 is a diagnosis with a binding product consequence
(whether Kiro can ever be `measured` rather than `estimated`), and P0 touches a
hashed, published evidence artifact where "just tidy it" would destroy the
audit trail.
**Status:** Ready to build
**Stress-tested:** Challenged: P0 is cosmetic, skip it → **rejected.** The report
currently reads as "copilot is broken" to anyone who scrolls past the divider —
it is the artifact cage publishes as evidence, and a self-contradicting evidence
file is worse than none. Challenged: P2 is a long shot, skip it → **rejected**,
and it's the most valuable of the three: it is the only remaining path from
`estimated` to `measured` for a whole agent, it costs ~15 minutes and no cage
code, and a negative result is itself the final answer Arpit needs. Riskiest
move: rewriting history in the report — forbidden; P0 **labels**, never edits,
the pre-fix numbers. Residual: kiro-cli may tunnel its own transport, in which
case P2 returns a documented "no" — still a result.
**Standing constraint: DO NOT COMMIT in `cage/`.** Commit in `cage-lab/` only.

  one is `estimated`, always.

- No cage source changes here; defects found are findings.
