## Task

New module `cage/graphifychat.py` + CLI wiring under `insights`, exactly per the
handoff §4 change map:

- `summarize(root, pol, since=None, agent=None, tool="graphify")` — call
  `chats.summarize` for the chat rows (never re-derive buckets/titles), join
  tool-filtered `ledger.savings` rows by `session` alone (they carry no agent); per
  chat: `receipts`, `Σsaved`, `Σraw_alternative`, `Σactual`, worst method
  (`METHOD_TRUST`) + min confidence, `tokens = tokens_in + tokens_out` (`None` on
  `from_credits`), `without = tokens + Σsaved`, `pct = 100 × Σsaved / without`. Tally
  `unassignable` (session=="" shim rows) and `unmatched` (no chat row) — footnoted,
  never dropped, never redistributed.
- Text table: `chat · agent · surface · gfx uses · tokens · without gfx · saved ·
  saved%`; rank `(-saved_sum, session)`; top-20 + counted cut, `--all` lifts;
  `--all-chats` includes receipt-less chats (gfx cells `—`). Default view =
  receipt-bearing chats only.
- Refusals per the handoff: no receipts → `—` (never 0%); kiro-cli credit chat →
  saved shown, token/pct cells `—` with reason; measured 0 → `0%`; negative saved
  rendered, never clamped.
- Footer: `GROSS_NOTE` verbatim · estimator-mixing caveat (`graphifymeter.toks`
  estimates vs metered tokens — the % is `modeled`) · worst-case method/confidence ·
  `coverage_lines()` rows when kiro appears · split-surface attach note (agent%
  precedent).
- Empty states diagnose (no receipts at all → `cage query graphify-coverage`,
  `cage doctor`, `cage insights roi`; filter-empty blames the filter only when true).
- `--csv`: untruncated, refused cells empty, adds `session raw_alternative actual
  receipts method confidence`.
- NO `--usd`, no dollars anywhere in this view.
