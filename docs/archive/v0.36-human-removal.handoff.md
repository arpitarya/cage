# Handoff — remove the Tier-1 human axis (substrate included)

**Do first.** `compare`, `verdict` and `matrix` all carry human total-cost lines; every
other queued item edits code this deletes. Building them first means editing twice.

**Decision (Arpit, 2026-08-01):** remove it completely, substrate included, shipped in
**v0.36 as a breaking change**. It will be rebuilt after the release — so this is a
*clean amputation*, not a deprecation.

---

## ⚠️ The trap that will bite an unwarned agent

**Cage has two different "human"s. Only one is being removed.**

| axis | what it means | code | fate |
|---|---|---|---|
| **Tier-1 human axis** | agent-vs-human *cost/time* baseline | `human.py` · `humanview.py` · `trend.py` · `attention.py` | **DELETE** |
| **Provenance `origin`** | *who authored* a commit — human or agent | `origin.py` · `originrecord.py` · `verifycmd.py` | **KEEP, untouched** |

They share a word and nothing else — separate enums, separate files, separate plan
sections. `ORIGINS = ("human", "agent", "agent-autonomous", "unknown")` in `schema.py`
belongs to **provenance** and stays.

## Scope

### Delete outright

- `cage/human.py` (77) · `cage/humanview.py` (162) · `cage/trend.py` (121) ·
  `cage/attention.py` (187)
- `cage human` command group (`show` · `record` · `outcome` · `quality`)
- `--human` on `insights matrix` and `insights calibration`
- `tests/test_human.py` · `test_human_cmd.py` · `test_human_law.py` · `test_attention.py`
- `docs/human-baseline.design.md` → `docs/archive/`

### Substrate contract change (plan §3, §4.10)

- `schema.py` — drop `gap_ms` from calls and `"minutes"` from `UNITS`
- `transcript.py` — stop stamping `gap_ms` at import
- `convert.py` — remove the `minutes` branch (it lazily imports `human`)
- `constants.py` — `IDLE_CAP_MINUTES`
- `data/cage.toml` — all seven `[human.*]` sections

**Readers must still tolerate old rows.** Ledgers are append-only and are never
rewritten, so existing rows carrying `gap_ms` or `unit="minutes"` must not crash a
read. An unknown extra key is already ignored; a `minutes` receipt now has no USD
route — decide explicitly: skip it from money views with a footnote, or price it `$0`.
**Do not silently drop it from a total.**

### Edit, don't delete

- `compare.py` · `verdict.py` · `study.py` — remove the total-cost line (agent $ +
  human minutes × rate) and the `--agent-only` flag that suppressed it
- `matrix.py` — the anchor row and vs-human columns
- `calibration.py` · `quality.py` · `taskgroup.py` · `estimate.py` — human paths
- `explain_data.py` — the `human-axis` concept and the human-cost calculation entries
- `csvout.py` — human/trend CSV views
- `report.py` · `roi.py` · `attribution.py` — any human-conditional branch
- `policy.py` — `[human]` loading, `CAGE_HUMAN_RATE`

### Wiring migration (CLAUDE.md rule — non-negotiable)

`cage human` exists in released versions. Removing a verb without a `verbmap.REMOVED`
entry makes it exit 1 silently on every machine that has it — the exact failure that
shipped broken from v0.28.0 to v0.32.0. Add entries for `cage human` and its
subcommands. `tests/test_cli_tiering.py` grep-gates source, assets **and** dev tooling
(`justfile`, `install.sh`) for stale spellings.
