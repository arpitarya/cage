## Constraints (hard)

- stdlib only (`datetime`); no clock, no random; **no datetime object enters a
  stored row** — the compare stays a string compare.
- Fail-open on the capture path: an unparseable timestamp yields no window, never
  an exception into `authorcapture`.
- **Never rewrite, purge, backfill or migrate a provenance row**, and **do not
  invalidate the `_authorship` cursor** — handoff §5.4 explains why forcing a
  re-read would make the ledger worse, not better.
- No `method` value moves. This changes *which sha* a row lands on, nothing about
  how strong the row claims to be.
- Do not modify: frozen rows · `schema.py`'s ts stamp · `verbmap` · wiring modules ·
  CHATS-AUTHOR's surface · REV-HARDEN's short-sha item (related, separate).
