# Proposal — the cage skill set

Cage already ships one skill (`/cage`, via `cage setup` — status + query pointers).
The ledger + explainer registry make several more nearly free: **a skill is prompt
text over surfaces that already exist**, and every number a skill shows inherits
cage's method tags. Candidates, ranked:

| # | skill | what it does | backed by | effort |
|---|---|---|---|---|
| 1 | **cage-analyst** | "what did this week cost / which tool earned its keep" — runs report/attrib/roi/verdict, explains method tags, never invents a number, points at `cage query` for formulas | existing read surface + MCP | prompt only |
| 2 | **cage-doctor-triage** | walks a capture failure: doctor → paths → wiring → the runnable fix; knows the F1 class (dead shim ≠ not installed) | doctor/--paths/--wiring | prompt only |
| 3 | **cage-task-closer** | reminds/performs `cage task outcome` at session end with a validated label — feeds compare/estimate/calibration, the surface starved for closed tasks (NET-1's whole problem) | task group | prompt only |
| 4 | **cage-adoption-nudge** | when the agent solves a repo question the expensive way, suggests the graphify query and cites the receipt it would have produced | ADOPT view + usage rows | needs ADOPT |
| 5 | **cage-lab-runner** | drives a cage-lab cell: pre-flight PATH proof, per-cell record template, prompt-count logging (the D3/D4 lesson) | docs/cage-lab/ | prompt only |
| 6 | **cage-release** | the release checklist as a skill: changelog · README what's-new · test count · tag → GitHub release → CI publishes; refuses local publish | CLAUDE.md release rules | prompt only |

**Rules for all:** a skill never computes a number itself — it runs cage and quotes it
(method tags survive verbatim); refusals (`INSUFFICIENT DATA`, UNPRICED) are relayed,
never smoothed; skills live in `data/` beside the existing one and install via
`cage setup` (three agents, always — Claude skill · Copilot prompt · Kiro steering,
same fan-out as everything else).

**Start with #1 + #3:** the analyst is the demo-able one; the task-closer directly
feeds the evidence pipeline every other insight is starved for.
