## The model, unchanged

| artifact | answers | lifetime |
|---|---|---|
| **Run report** | "What happened in *this* run?" | immutable; **no later status ever** |
| **Finding doc** | "What is this defect's status *now*?" | mutable status, append-only history |
| **History index** | "What runs exist, how did numbers move?" | one row per run |

## Constraints (hard)

- **Transcribe, never recompute.** Every number comes from the published text.
- **No paid calls.** Nothing is re-run; no ledger is read.
- **Nothing is deleted or rewritten** — supersede only.
- **A run report carries no later status.** If a fact wasn't observed in that
  run, it belongs in a finding doc.
- Every number in the original appears in **exactly one** new artifact — none
  lost, none duplicated.
- **DO NOT COMMIT in `cage/`**; append a `cage/docs/IMPLEMENTATION.md` entry.

## Guardrails

- **STOP and ask if:** a finding's current status genuinely can't be determined
  from the record (say which, and what evidence would settle it) · a number can't
  be attributed to exactly one artifact · splitting would require re-reading the
  real ledger (it must not).
- Do not "improve" a historical observation while transcribing it. If the 07-22
  run said something later shown wrong, that text is preserved in the run report
  as *what the run observed*; the correction lives in the finding doc.
