## The one rule that governs everything else

**Rebuild the configuration, never the corpus.**

| layer | action |
|---|---|
| Fixture source files (the toy package) | **PRESERVE byte-for-byte** — hash before, assert after |
| `graphify-out/`, `CLAUDE.md`, `.claude/`, `.cage/`, `bin/` | **DELETE and re-derive** via the tools' own installers |
| `golden/runs/` | delete freely (scratch) |
| `golden/captures/` | **DO NOT TOUCH** — arm A's baseline |
| `cage/docs/regression/**` | **NEVER delete or edit** — published, hashed, append-only |

A freshly-authored fixture would make arm B's token delta measure *"different
repo"* instead of *"graphify installed"*. That confound is the reason this task
exists in this shape.

## Task

1. **Pre-flight manifest.** sha256 every fixture source file, every file under
   `golden/captures/**`, and every file under `cage/docs/regression/**`. Save as
   `workspace-pre-g05-manifest.json`. Then `mv workspace/ workspace.pre-g05/` —
   move aside, do not delete.

2. **Discovery before execution.** Run `graphify --help` and
   `graphify claude install --help` against the **installed** binary. Record the
   real verbs, flags, and versions. Plan §1.1's table came from docs; the binary is
   ground truth. If `--strict` exists, **record it but do not enable it** — an
   extra variable in arm B.

3. **Rebuild, in this order, capturing stdout of every command:**

   ```
   0. hash fixture sources                    # the control
   1. git init; restore fixture files from workspace.pre-g05 UNCHANGED
   2. graphify <build verb>                   # record exact verb + flags
   3. graphify claude install                 # CLAUDE.md steering + PreToolUse hook  ← was MISSING
      (SKIP `graphify hook install` — commit-time graph rebuild adds capture noise)
   4. cage setup --claude                     # .cage/, cage.toml [sources], bin/graphify shim, MCP
   5. cage doctor
   6. re-hash the fixture                     # must equal step 0, or the A/B is void
   ```

4. **Snapshot `CLAUDE.md` after step 3 and after step 4, and diff them.** Both
   tools write that file. If one clobbers the other's block, **that is a finding**
   — record it, find the order that preserves both, and report. Do not hand-patch
   the file into the state you wish it were in.

5. **Record how the PreToolUse hook invokes graphify** — bare command, absolute
   path, or Python entry point — verbatim from the settings file. cage's
   `bin/graphify` shim meters by **PATH interception**, so an absolute-path
   invocation means the query fires and cage never sees it. **Do not fix this.**
   Recording it predicts G1's outcome before a single paid call is spent.

6. **Write the provenance artifacts** in `workspace/`:
   - `SETUP.md` — every command in order, output summaries, tool versions, date,
     the `CLAUDE.md` ownership observation, and the hook's invocation form.
   - `rebuild.sh` — the same sequence, re-runnable, exiting **non-zero** on any
     verification failure below.

7. **Verify, then clean up.** Only once every check passes: delete
   `workspace.pre-g05/`, commit in **cage-lab only**, update the docs (§9.5 of the
   handoff), and report.
