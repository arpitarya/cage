**Model: Opus.** The relabel is mechanical, but the rest is method-tag and

## The problem

`roi`/`verdict` know what a tool spends **on itself**, not what it costs **to use**.
graphify is AST-only and declares `$0`, so `verdict graphify` computes
`net = gross − 0 = gross` and prints **SAVING** — on sessions leg D measured costing
~14% more.

## Tasks

**1. K — relabel gross.** Everywhere `saved` surfaces (receipts, `insights attrib`,
`roi`, the ceiling footer): *"avoided read cost (gross) — excludes the cost of using the
tool"*. No maths changes. Do this first; the rest depends on it.

**2. NET-2 — `verdict` must stop over-claiming.** When own-cost is absent/zero and no
cost-of-use figure exists, it must not assert a bare SAVING. Choose a distinct verdict
naming the exclusion, or INSUFFICIENT DATA on the net line with gross still shown.
Point the reader at `cage insights compare` (the measured alternative).
**Keep `verdict` a pure composer** — this is a refusal rule, not a new statistic.

**3. NET-3 — task-level net saved.** `net = gross − the measured cost of the task's
turns attributable to tool use`, joined via `taskgroup`. Render **beside** gross, never
instead of it. Gross is `modeled`, the subtrahend `measured`, the result `modeled` with
its **own** (lower) confidence.

## Hard constraints

- **Per-query net is impossible** — graphify receipts are call-less (a `task`, no
  `call`). Do not invent a link. Task-level only.
- **Never let net read as `measured`.** It inherits gross's modeled counterfactual.
- **Never silently equal gross.** Unavailable ⇒ say unavailable.
- **Gross must survive.** Reporting only net destroys the comparison this finding exists
  to make visible.
- Determinism: same ledger + policy ⇒ same tables. No clocks, no randomness.
- stdlib only; fail-open write paths; typed `CageError` only at the CLI boundary.
- Do not touch `docs/regression/**`. No commits in `cage`.

## Decide and state (not pre-decided)

**What counts as "attributable" cost?** The whole task · only turns containing a
tool-use block · turns within a window of the receipt `ts`. Each is defensible and each
yields a different number. Pick one, justify it, document it in `FORMULAS.md`, and make
it visible via `cage query`. **Do not pick silently** — this single choice determines
whether net is honest or arbitrary.

## Out of scope

The A/B answer. `cage insights compare` already does it and only lacks data
(`MIN_COMPARE_N = 5`; leg D produced 1). Do not build a second comparison path.
