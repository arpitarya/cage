## Constraints (hard — handoff §6)

- **Store-verbatim only.** Absent in store ⇒ absent in row. NEVER estimate tokens
  (chars÷4 / cumulative-context / chunk-count are banned as token facts; `chunks`
  is a chunk count). `credits` is None-sentinel — absence ≠ 0.
- **Counts-never-content by whitelist**: CLI parser reads only
  `request_metadata` / `user_turn_metadata` / `model_info` keys — never
  `history[].user`/`.assistant`/`content`/`latest_summary`, never auth tables.
  IDE parser: explicit whitelisted columns only, never `SELECT *`.
- **ADR 0006**: IDE-source rows land in the kiro sink's ledger only; CLI-source rows
  are workspace-scoped. Never re-decide routing — inherit it from the leg you hook.
- **Read-only SQLite** (`mode=ro&immutable=1`), never checkpoint/lock; fail-open
  per file/db with `CAGE_DEBUG` trace; idempotent re-import; $0 stdlib.
- Do not modify: goldens, `tests/fixtures/transcripts/` verified corpus, pricing
  (`creditprice`), `docs/CLI.md` (no new command).
