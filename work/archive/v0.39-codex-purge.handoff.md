# Handoff — purge Codex, and the DEBT review it triggers

**Decision (Arpit, 2026-08-01):** remove everything referencing Codex. Support was
already dropped in v0.33.0; this removes the *residue*, including the legacy-detection
scan I argued to keep. **That trade-off is recorded below, not hidden** — it is Arpit's
call to make and it is made.

---

## ⚠️ STOP — there are THREE different "Codex"es, and only one is being removed

This is the two-different-"human"s trap from v0.36, with an extra head. A blind
`grep -i codex && delete` **breaks live pricing for Copilot users.**

| # | what | where | fate |
|---|---|---|---|
| **1. Codex the agent** | `codex_home()`, `wiringscan`'s `~/.codex/config.toml` scan, doctor's `.codex/hooks.json`, `CODEX_HOME` in the doctor bundle | `paths.py` · `wiringscan.py` · `doctorcmd.py` · `doctorbundle.py` | **DELETE** |
| **2. Codex the MODEL family** | `gpt-5.3-codex`, `gpt-5.2-codex`, … — **OpenAI model ids that Copilot also emits**; plus `policy.py:164`'s effort-suffix fold (`…-codex-high` → `…-codex`) | `data/prices.toml` (20 rows) · `policy.py` | **KEEP — untouchable** |
| **3. Codex as a stale enumeration** | prose listing agents that don't stamp `project` ("Claude today; Copilot/Kiro/Codex leave it empty") | `schema.py:70` · `ledger.py:287` · `report.py:576` · `proxy.py:4` · `runshim.py:166` · `paths.py:14` | **drop the word**, keep the sentence |

**The comment above `prices.openai."gpt-5.3-codex"` says it outright:** *"OpenAI — Codex
CLI + Copilot (both emit gpt-family ids)."* Those rows are load-bearing for a supported
agent. Deleting them silently UNPRICES real Copilot traffic.

## What is lost by removing category 1 — stated, then accepted

`wiringscan` currently finds a **stale cage command in a pre-v0.33 `~/.codex/config.toml`**
on a machine that still has one. Removing the scan means such a machine keeps a dead
`cage …` verb forever, undetected — the user-level F1 class that CLAUDE.md's
wiring-liveness rule exists to catch.

**Accepted because:** Codex has been unsupported for five releases; anyone still holding
that file is not a cage user on any supported path; and carrying scan code for a
product we will never support again is its own liability. **Record this in the CHANGELOG
`Removed` entry** so the trade is visible, not silent.

## DEBT review — the purge is `paths.py`'s first contact

[structural-debt.md](v0.39-structural-debt.proposal.md) proposes: *"the next change that
touches a `paths.py` concern moves that concern out with it."* **This is that change** —
it touches the agent-home helpers (`codex_home` sits beside `copilot_home`, `kiro_home`).

**But do NOT split `paths.py` in this change.** The seam here is *agent homes*, which the
proposal doesn't name (its seams are `routing.py`, `logsources.py`, `footprint.py`), and
mixing a deletion with a move makes both unreviewable. **Instead: add `agenthomes` to the
proposal's named-seam list**, so the next touch there does the move with a clean diff.

Otherwise the DEBT proposal reviews as **sound and still correct** — no changes needed.
Its rule-not-project framing is right, and part 2 (the bare-`cage` landing) is untouched
by any of this.
