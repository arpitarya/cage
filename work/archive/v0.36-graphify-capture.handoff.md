# Handoff: graphify capture — usage rows · transcript detection · forward model

**One-liner:** Make graphify usage impossible to miss (usage rows + transcript-side
detection at import) and give cage an honest forward model of graphify savings
(history band · graph-derived ceiling · verdict composition).

**Owner / executor:** Claude Code — **Model: Opus.** This touches the capture path
(fail-open), transcript parsing across agents, receipt dedupe design, and new
method-tagged numbers — diagnosis-adjacent work where a wrong call is expensive.

**Status:** Ready to build. **No paid LLM calls.** Sequenced **before G1**.

**Stress-tested:** the debate gate challenged three things.

1. **"Transcript detection works for all three agents"** — unproven for
   Copilot/Kiro; their logs may not carry tool-call bodies. **Blocked the
   all-agent scope**: GC0 is a gating probe; claude ships first, others are
   HONEST-LIMIT until probed (the `gap_ms` precedent). Residual risk: none — the
   limit is explicit.
2. **"Report-read receipts could inflate savings"** — a Read of GRAPH_REPORT.md
   doesn't prove the agent *would have* read N source files. **Survived amended**:
   report-read receipts get a distinct `report-read` label, lower confidence,
   still `modeled`, and are footnoted separately in every view — never conflated
   with query receipts. Calibration can later score them.
3. **"Forward model = forecasting without data"** — **survived** because it's
   three separately-gated claims: the history band refuses below
   `MIN_ESTIMATE_N`; the ceiling is deterministic from the graph (no history
   needed, printed as a bound); verdict composes and refuses as today.

**Plan of record:** [graphify-capture.plan.md](graphify-capture.plan.md) (GC0–GC6).

## 1. Context & background

G0.5 proved graphify's PreToolUse hook spawns no process — every existing capture
route (PATH shim, native shim, hook) is invocation-gated, while real usage may be
invocation-less (the agent reads `GRAPH_REPORT.md` instead of scanning files). A
parse-miss today files nothing, so usage is invisible — the root ambiguity behind
the "0 real receipts across 36,451 calls" mystery. Plan §1 has the full evidence.

## 5. Technical approach (decided)

- Transcript detection is **pull-based, at import** — never a watcher (ADR 0002).
- Reuse `graphifymeter`'s parser/counterfactual — one implementation of the
  formula; FORMULAS.md points both routes at it.
- Report-read counterfactual = the graph's own source-file corpus (GC5b shares
  the computation) — one place, used twice.
- Usage rows in `state/` because state is never read by derived views — the
  no-perturbation property holds by construction, then is tested anyway.
- Forward model copies the estimate/calibration pattern rather than inventing a
  new statistical surface.

## 6. Non-negotiables / constraints

- **stdlib only; `dependencies = []`.** No tokenizer, no ML on the default path.
- **Fail-open on the write path** — detection errors must never break an import.
- **Method law**: everything new here is `modeled` (or a usage row with no method
  at all). Nothing may render as `measured`. Report-read ≠ query receipts,
  visibly.
- **Determinism**: no clocks/random in derived views; transcript receipt ids
  carry the only entropy, derived from row content.
- **Counts never content**: usage rows carry `args_hash`, never the query text.
- **A parse miss still files no receipt** — the usage row is the only trace.
- **Never fabricate Copilot/Kiro support** — GC0's verdict is written down even
  (especially) when it's "the log doesn't carry it."
- **Do not touch:** goldens except by re-blessing; `work/regression/**`; the
  native-shim handshake; graphify itself.

## 8. Edge cases & risks

- **Same query via shim AND transcript** → GC3's dedupe; test it explicitly.
- **Cited file drifted/deleted by import time** → skip it (existing
  `_raw_alternative` behavior); note the import-time-drift caveat in FORMULAS.md.
- **Empty query result** → no receipt (nothing saved), usage row `outcome=empty`.
- **`graphify-out/` read via absolute vs relative path in the transcript** →
  match on path suffix, not equality.
- **A Bash command containing `graphify` in a string but not invoking it**
  (e.g. `grep graphify`) → anchor the matcher on command position; test the
  false-positive case.
- **Kiro/Copilot logs carry partial tool info** (command but no result) → that's
  a usage row without a receipt — exactly what GC1 exists for; record the
  half-support honestly.
