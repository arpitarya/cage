# Handoff — the debts v0.38 left behind

**v0.38's code is sound** — marker drift tested, `GRAPHIFY_SHIMS` a single enumeration,
the `%ERRORLEVEL%` parse-time trap pinned by name. **What's missing is the honesty
surface around it**: seven items, all documentation-or-explainer, none deep.

Do these **before v0.38.0 is committed** — they are the same change, not a follow-up.

---

## 1. `docs/restricted-environments.md` is gone, and 8 source files cite it

**Worst of them.** The doc existed (129 lines: Tier 1 python-launcher · Tier 2
`cage.pyz` · Tier 3 mirror · the WDAC caveat · a validation checklist) and was **deleted
in the v0.36 hookless sweep** (`b2c4253`). These still point readers at it:

`clicmds.py:438` · `doctorcmd.py:30,439` · `paths.py:59` · `policy.py:260` ·
`runshim.py:30,144` · `CLAUDE.md:738`

**Restore it from git** (`git show b2c4253^:docs/restricted-environments.md`), then
bring it current — the launcher-mode surface has changed since, and **§2 below belongs
in it**. Do not rewrite from scratch; the tier structure is good and the WDAC caveat is
hard-won.

> **My review error, for the record:** I first reported three broken CLAUDE.md refs.

## 2. GF-LAUNCHER is a user-facing gap with no user-facing statement

Under `--python-launcher` there is no `cage` on PATH, so **neither twin meters** (B5).
Today that lives only in OPEN-WORK.

The README now says graphify reaches cage on Windows **and**, two sentences later,
recommends `--python-launcher` for locked-down endpoints — **without saying the two
cancel out**. A reader on a WDAC-locked machine gets both halves and never the
interaction. That is the human-axis README failure in a fresh spot, three days later.

- State it in the README Platforms line (one clause).
- State it fully in the restored restricted-environments doc.
- `cage doctor` should say it when launcher mode is on **and** an interceptor is
  installed — that combination is precisely where the silent gap bites.

## 3. No `cage query` entry for the twin pair

Every comparable structural fact has one — `stale-wiring`, `kiro-routing`,
`portable-wiring`, `savings-axis`. Doctor can now **fail** on a root carrying only the
twin this OS can't resolve, and the user has no explainer to run.

Add a concept entry (id: `graphify-shims` or similar) covering: why two twins · PATHEXT
has no extensionless entry · `.EXE` precedes `.CMD`, so resolution is directory-major /
extension-minor and cage's `bin/` is safe · the marker set is the identity check ·
D1's `call`-not-`exec` divergence · and the launcher-mode gap from §2. Live-interpolate
paths from `paths.graphify_shims`, per the registry's existing pattern.

## 4. No ADR — and three decisions here need one

Load-bearing, expensive to reverse, and the reasoning exists only in a handback:

- both twins install on **every** OS (a committed `bin/` must be byte-identical)
- **hand-paired, not templated**
- the contract lives in `docs/`, not beside the shims (package data would ship a spec in
  every wheel)

The middle one matters most: a future agent *will* see two files implementing one
contract and try to generate them — exactly what I proposed and you correctly rejected.
Author from `adr/TEMPLATE.md` as **ADR 0007**, with a real veto condition:

> **Contingent:** templating becomes revisitable only when a **third** interceptor exists
> *and* at least two share a syntax family. **Invariant:** the written contract, not the
> code, is the shared artifact — that does not change with tool count.

## 5. The cage-lab manual doesn't know the twin exists

Zero mentions of `graphify.cmd`, PATHEXT, or the pair across all five lab docs. The lab
is the **fidelity** authority and Windows is now a claimed platform.

Minimum: `03-verify.md` states the lab validates the **POSIX twin only**, so a green lab
run is never read as Windows coverage; `01-setup.md`'s PATH-proof law notes it proves the
POSIX shim.

## 6. Write down the CI-corpus lesson (small, high value)

The first CI corpus was too small, so every query returned honestly `unmeasurable` — the
leg **passed while asserting nothing**. Same class as a test pinning the wrong table.
One line in `shim-contract.md` or the CI section: *the corpus must stay large enough that
a query is genuinely cheaper than the files it cites, or the leg is vacuous.* Ideally the
CI check fails loudly on an all-`unmeasurable` run rather than passing.

`windows-graphify-interceptor.md` was archived 2026-08-01 as the worked example, and the

proposal's living-spec anchor** — update the archived proposal's header to name it

Also check no *other* proposal has quietly been implemented: as of 2026-08-01 the
