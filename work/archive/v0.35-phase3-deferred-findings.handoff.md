- [ ] **F3 — Kiro "found but empty" is visible.** `cage doctor` distinguishes
      "Kiro log found but ~0 tokens" from a healthy agent, and recommends Kiro's
      higher-fidelity proxy path (`cage proxy` / `cage meter -- …`). Import logs the
      resolved Kiro `src`: existed?, byte size, rows parsed, tokens summed — so
      "found but empty" is never again invisible.
- [ ] **F5 — Cache split in `report --usd`.** One added line/column: cached vs fresh
      input tokens and the cache-read share of cost. The headline stops implying

      report structure changes.**
- [ ] **F7 — `gap_ms` coverage.** Confirm `transcript.parse` stamps `gap_ms` across
      the whole Claude transcript, not the ~1% sliver measured. Where it's genuinely
      skippable (no previous-turn timestamp), **log the skip** rather than stamp a
      fabricated gap. Report the before/after coverage on a real transcript.
- [ ] **Tests** for each behaviour; **test-count line** refreshed (CLAUDE.md rule).
- [ ] **Release hygiene:** CHANGELOG entry, README "What's new" replaced,
      `__version__` bumped, handoff/prompt pair archived on the shipping release.

## 3. Scope

**In scope:** the three fixes above, their tests, one bundled release.

**Out of scope (explicit — the scope-creep traps):**

- **Rewriting Kiro capture.** Its token log is coarse and input-only *by nature* —
  F3 makes that *visible and recoverable via the proxy*, it does not make the raw log
  richer.
- **Restructuring `report`.** F5 is one honest line, not a new view.
- **Inventing `gap_ms`** where the source lacks a previous-turn timestamp. Coverage
  goes up only where the data legitimately supports it.
- **Anything touching the capture hooks or `capture.log`** — that's F6-fix / Phase 4
  territory, deliberately not here (see the field-gate note,
  `work/regression/2026-07-24-field-gate-post-heal-check.md`).

## 5. Non-negotiables (cage-wide)

- **`$0`/stdlib-only; deterministic** (derived views byte-identical).
- **Fail-open on capture writes; every swallow logged under `CAGE_DEBUG`.**
- **Counts-never-content PII guard** — the F3 import log is counts/paths/sizes only,
  never token *content*.
- **`method` never reads `measured` for a projection.**
- GitHub release is the **sole** publish trigger — never publish from a laptop.
- CLAUDE.md steering edits are **proposed for review**, never silently rewritten
  (except the mechanical test-count line the rule mandates).

## 6. Edge cases & risks

- **F3:** confirm the macOS Kiro path is current — the report used the VS-Code Kiro
  `globalStorage` (`~/Library/Application Support/Kiro/User/globalStorage/…`); verify
  against a **CLI-Kiro install** too. *OPEN — needs a real Kiro install to check.*
- **F5:** cache-read cost is billed at 0.1× — make sure the split uses the *actual*
  price multiplier, not a hardcoded fraction, so it stays correct if pricing changes.
- **F7:** the first turn of every session legitimately has no prior timestamp → an
  expected skip, not a miss. Don't let "improve coverage" push a bogus gap onto it.
