# Handoff: SURFACE-CUT — remove the data group, report, and five insights views

**One-liner:** delete `cage data` (all **eight** subcommands), `cage report`, and
`cage insights compare|estimate|calibration|attrib|adoption` — commands, handlers, modules,
tests, goldens, MCP tools and docs.

**Survives in `cage insights`:** `chats` · `graphify` · `commits` · `commit` · `why`.
**Survives overall:** `import` · `setup` · `doctor` · `query` · `insights` (those five) ·
`task` · `authorship` · `policy` · `study` · `mcp`.

**Owner / executor:** Claude Code · **Model:** Opus (deletion with live entanglements)

**Status:** Ready to build. **P0 is a STOP check** (§2) — the tree may be mid-flight.

**Note for the record:** `cage insights attrib` is what `docs/PLAN.md` §4 calls *"the
attribution engine (the part that's actually novel)"*. Removing it narrows what cage **is** —
the ADR should say so plainly, and PLAN §4 will need rewriting, not just annotating.

**Stress-tested:** the gate challenged scope five times; Arpit chose maximal each time.
(1) `cage data` is **eight** subcommands (`docs/CLI.md:344`), not the six first counted —
`meter` and `graphify` were missed. (2) Three of the eight are capture/maintenance, not
reporting — **all eight go**. (3) `report.py` is a **library**, not a leaf — chosen: delete
it and its dependents. (4) `cage study report` (goldens S3/S4) is a *different command* and
**survives**. (5) `attrib` + `adoption` added late; both are clean leaf deletes now that
`report`/`netsaved`/`matrix`/`verdict` are gone.

**Residual risks:** capture becomes `cage import`-only; ledger retention loses its only
pruning path; the kiro proxy — the kiro research doc's #1-ranked *"ONLY path to all five
values"* — closes permanently; the `bin/graphify` PATH shim installed by `cage setup` breaks
on every machine; and the MCP server drops to two tools, which may not be worth keeping (§10).

## 1. Context & background

- USAGE-ONLY (ADR 0011) shipped: money gone, fifteen modules deleted, zero `--usd` in
  `cli.py`, `tests/test_usage_only.py` is the regression pin.
- What remains of cage's output surface is disproportionate to a usage meter: an 894-line
  `report.py`, an **eight**-command `data` group, a dashboard, a proxy, and three task-grain

  metric ledger, and `report --by route` collapses to `chat`. These deletions remove every
  symptom; §10 covers what the defect leaves behind.

## 4.6 `cage insights graphify` — what keeping it requires

Its true data-path closure is **47 cage modules** (AST import graph, barrier = the CLI
dispatch layer; for scale `insights chats` is 45, `commits` 34, `why` 23). Exactly two of
the 47 appear on the delete list:

- **`graphifymeter`** — kept (§9.9 #2).
- **`report`** — drops out of the closure once C's rescue lands. No exception needed.

**Receipts keep flowing.** An earlier draft claimed the view would go stale. It will not:
`graphifytx.detect_and_file*` runs at `cage import` for all three agents
(`importcmd.py:546` claude · `:759` kiro-cli · `:895` copilot). GC3 / ADR 0005's content-key
deferral means shim-and-transcript never double-file. **What is lost is invocation-time
metering coverage, not capture.**

**Coupling:** `graphifychat` imports `chats` — graphify and `insights chats` share 45 of 47
modules. Cutting `chats` later would take graphify with it.

## 9.9 Corrections found after the first draft (2026-08-14)

Three first-draft claims were wrong. Each would have broken a **surviving** command.

1. **`kiro_routed_line` is called from `clicmds.py`, not `chats.py`.** Sites: `:79`
   (`cmd_report`, dies), **`:123` (`cmd_chats`)**, **`:138` (`cmd_graphify_chats`)** — the
   last two survive. `clicmds`'s import list does not currently include `chats`.
2. **`graphifymeter.py` is a shared library, not a command module.** Surviving module-level
   importers: `graphifytx.py:34` (six symbols) and `repoceiling.py:26` (`toks`). Chain:
   `graphifymeter → graphifytx → graphifychat → cage insights graphify`. **Not deleted.**
3. **`report.overview` / `render_overview` back the bare-`cage` summary**
   (`clicmds.py:90–91`, goldens `O1`/`O2`) — a command not on the delete list. See §10.

A fourth correction, not a break: **`cage insights graphify` does not go stale** (§4.6).

**Standing rule this produced:** any "its only caller is X" claim must be re-verified by
grep — both `from cage.<name> import` and `from cage import .*<name>` — and the grep output
**reported, not asserted**. Two of three such claims in the first draft were false.
