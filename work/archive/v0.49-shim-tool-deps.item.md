# SHIM-TOOL-DEPS — B3's content check needs a tool it does not check for

**A twin can select ITSELF as the real binary when `grep` does not resolve** — and then
re-execs forever. That is the recursion [shim-contract.md](../../docs/shim-contract.md) B1–B4
claim is structurally impossible.

**Measured, not reasoned.** A test run with `PATH` reduced to `/bin` (no `/usr/bin`,
where macOS keeps `grep`) hung for the full 120-second timeout. The chain: `grep` is
absent → `_cage_is_interceptor` errors → **every** candidate reads *not an interceptor*
→ the twin claims itself as `REAL` → `exec "$REAL"` re-enters the same file.

**Pre-existing.** Not introduced by GF-LAUNCHER's arm 2; the same hole is in every
shipped version of the POSIX twin. The `CAGE_GRAPHIFY_SHIM` re-entry guard does not save
it — that guard is only set on the *metering* path (B1), and this loop never reaches it.

## Why it may still be fine

The population is plausibly zero: a PATH without `/usr/bin` is exotic, and the twin's own
`#!/usr/bin/env bash` already needs `env` at an absolute path. **State it as a decision,
not an oversight** — that is the whole point of filing it.

## The fork, unresolved

| option | cost |
|---|---|
| fail **closed** — no usable `grep` ⇒ refuse to claim any candidate, exit 127 | turns an exotic hang into an exotic failure; B4 already has a 127 path |
| resolve `grep` at an absolute path (`/usr/bin/grep`, `/bin/grep`) | hardcodes a layout that differs across distros |
| bound the walk — never claim a candidate whose realpath is this file | narrowest fix, and it closes self-selection *only* |
| accept, and say so in the contract | free; leaves a hang, which is the worst failure shape a fail-open path can have |

**A hang is worse than either a failure or an unmetered run** — that is the asymmetry
that should decide this, and it argues against "accept".

## Binds any fix

**Both twins together** ([ADR 0007](adr/0007-graphify-twin-pair-hand-paired-not-templated.md)):
the cmd twin has the identical dependency on `findstr`, plus a `where` fallback that has
the same property. And the fix must not disturb B3's three-copy marker set.

Reproduce: `tests/test_gf_launcher_arm2.py::test_passthrough_is_unchanged_when_cage_is_unreachable_entirely`
carries the note; shorten its PATH to `/bin` to see the hang.
