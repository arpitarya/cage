```

importcmd.py:759  graphifytx.detect_and_file_kiro_cli(...)       kiro CLI store
importcmd.py:895  graphifytx.detect_and_file_copilot_vscode/...  copilot
```

content-key deferral means a query seen by both shim and transcript files exactly one
receipt, so removing the shim leaves the transcript route as sole filer with no

**What is actually lost:** invocation-time metering for runs the transcript/store routes
cannot observe. State that precisely in the ADR — reduced coverage, not stopped capture.
