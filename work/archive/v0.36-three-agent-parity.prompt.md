## The gap

`cage-lab` was built wiring **claude only**. Arpit runs **all three agents, always**.
Two consequences, both silent:

1. `cage setup --claude` gives copilot and kiro **no MCP wiring** in that workspace.
2. Only `graphify claude install` (and maybe copilot) ran in `workspace-on` — so a
   missing agent's ON cell is really a **second OFF cell**, and it reports a zero that
   *looks like* an adoption finding but is a setup bug. That misreading is the whole
   reason this must be fixed before any question is asked.

**Law 0 (now in the manual): all three agents are always in scope.** Never a per-run
choice. A surface that can't be driven is `NOT AVAILABLE`/`UNPROVEN` — never dropped.

## Standing laws

1. **ZERO dummy data.** Nothing simulated, ever. A step that can't complete is
   reported.
2. **Isolated ledger** — `cage-lab/labledger/`; **`~/.cage` is never written** (check
   its mtime before and after).
3. **The cage tree stays uncommitted.** Commits in `cage-lab` only.
4. **`cage/work/regression/**` is never touched.**
5. **Never hand-write a steering block** — tool-owned installers only.

### 2. Wire all three agents in BOTH workspaces

```bash
# workspace-off — no graphify anything
cage setup --all --no-graphify
cage setup --status          # must list claude, copilot AND kiro

# workspace-on
cage setup --all
cage setup --status          # must list claude, copilot AND kiro
```

`--no-graphify` on the OFF side is required, not optional: the shared `.venv` puts a
real `graphify` on PATH for both workspaces, and plain `cage setup` installs an
interceptor shim whenever graphify resolves at all — which would itself be a graphify
artifact in the arm that must have none.

### 3. Run ALL THREE graphify installers in `workspace-on`

```bash
graphify claude install      # CLAUDE.md steering + PreToolUse hook
graphify copilot install     # ~/.copilot/skills — passive /graphify skill
graphify kiro install        # .kiro/skills + steering
```

- ⚠️ `graphify <agent> install --help` may **run the installer for real**. Discover
  carefully.
- Snapshot each agent-facing file **before and after** each installer and diff. Both
  graphify and cage write `CLAUDE.md`; if one clobbers the other, that is a finding —
  record it and find the order that preserves both.
- If an installer doesn't exist under that name, use the real verb from the CLI and
  **correct `work/cage-lab/01-setup.md` in the same change**.
