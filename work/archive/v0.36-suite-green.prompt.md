## Task 1 — G-SAV (one line, plus a judgement call)

`savings.record()` omits `ts` from its signature, so a caller's `ts=` is swallowed by
`**_ignore` and every savings row is stamped *now* — landing in the current month's
shard whatever the work's real date. `schema.make_savings` already accepts `ts`.

- Add `ts: str | None = None`; forward it.
- **Keep `**_ignore`** — three shim-boundary callers (`graphifytx` ×2, `graphifymeter`)
  depend on the fail-open push contract. Removing it is a separate decision.
- Make the shard test prove a **past-month** `ts`, not merely today's — a fix that only
  works for the current month is the same bug with better luck.

**Consider, and ask before doing:** a test asserting every keyword `make_savings` takes
is also explicitly accepted by `record()`. It would make the next silent drop
impossible — but it constrains the shim contract, so raise it rather than assume it.

## Task 2 — BUD-V-TEST (five tests, one example table)

confirm-bucket, orphan-warning) and used `[budgets]` as the worked example. The bundle
now ships `[budgets]` commented out by decision, so the mechanics can't run through it.

key · not already be another test's subject (`[tools] order` is taken). `[quality]` is
the likely fit — **verify it, don't assume**.
