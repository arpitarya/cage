## Constraints (hard)

- stdlib only; `dependencies = []`. Fail-open on the write path — a detection
  error never breaks an import.
- Everything new renders as `modeled` (or is a method-less usage row). Nothing
  may read as `measured`. Report-read receipts stay visibly distinct from query
  receipts.
- Determinism: no clocks/random in derived views; ids derive from row content;
  re-import is idempotent.
- Counts never content: `args_hash`, never query text.
- A parse miss files **no receipt** — usage row only.
- Never fabricate copilot/kiro support; GC0's verdict is recorded even when
  negative.
- Do not touch: `work/regression/**`, the native-shim handshake, graphify
  itself, goldens except by deliberate re-bless.
- **The cage tree stays uncommitted.**
