# Claude Code prompt — `cage insights adoption` (ADOPT)

**Model: Opus.** Not for the rendering — for the honesty boundary. The view's entire
value is distinguishing *never invoked* from *invoked and cage missed it* from
*invoked and cage cannot say by whom*, and blurring any two of those makes it worse
than nothing. Escalate nothing; if a distinction can't be drawn honestly, print the
refusal.

## The correction that shapes the whole build

The proposal promises "per agent × tool". **Per-agent is only derivable for the
transcript route.**

- Usage rows carry **no agent**, so half A is agent-blind.
- Shim/native savings rows carry an **empty session**, because a subprocess cannot know
  which agent spawned it. Only transcript-detected runs have a real session, joinable
  `savings.session` → `calls.session` → `calls.agent`.

**Build both halves, keep them visibly separate:**

**A. Totals + outcomes** (usage rows, exact, no join). Use the recorded `outcome` field
— `receipt` / `unmeasurable` / `empty` / `non-measured` / `error` — **do not re-derive
"missed"**; it is already a field. Break down by `op` and `route`.

**B. Per-agent** (savings rows with a session → `calls.agent`). Transcript route only.
**Shim/native must render as agent-unknown with a caveat naming the reason** — never an
"other" bucket, never attributed by timestamp proximity.

**"Never invoked"** = calls present, zero joined savings. Phrase as **no evidence of
invocation**, never as proof of non-use.

## Hard constraints

- **No currency in this view, anywhere.** Usage rows are diagnostic-only — never priced,
  never read by a derived *money* view, and there is a byte-identical test pinning that.
  This view counts them; keep the invariant intact and say so in the docstring so the
  next reader doesn't think it lapsed.
- **Derived view only** — no new capture, no schema change. If per-agent coverage turns
  out too thin to be useful, **that is a finding to report**, not a licence to add an
  `agent` field mid-flight.
- K4 inherits: claude's CLI/VS Code share a store ⇒ `surface` unknowable; `project` is
  the discriminator that works. Reuse `Footer`, don't reword.
- Determinism · CSV parity (§3.9) · MCP mirror, like report/attrib/roi.
- stdlib only; no commits; don't touch `work/regression/**`.

## Decide and state

**What the view does when the transcript route produced nothing** — i.e. every
invocation came via the shim, so half B is entirely agent-unknown. Print half A plus an
explicit "per-agent attribution unavailable (all invocations via the shim route)", or
suppress half B? Either is defensible; **silently printing an empty table is not.**
